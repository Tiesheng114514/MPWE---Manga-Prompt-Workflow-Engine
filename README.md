# MPWE - 漫画 AI 绘画工作流引擎

一个自托管的中文漫画 AI 绘画网站：用户注册后用大白话描述画面，就能用本地显卡生成漫画风图片。

## 功能

- **邀请码注册**：只有管理员发放邀请码，用户才能注册（不需要邮箱/手机号）
- **文生图**：内置 10+ 款漫画模型预设，选模型即自动配好参数，支持画质增强（超分放大 + 脸部修复）和 LoRA
- **AI 提示词 Agent**：输入大白话（如"雨夜一个女生撑着透明伞站在路灯下"），自动生成专业提示词
- **金币/银币计费**：API 用银币 🥈、图片用金币 🪙，两个钱包分开扣费
  - 新用户注册送：API 0.5 银币 + 图片 3 金币
  - 右上角「免费充值额度」：过一遍人机验证，再送 API 0.5 银币 + 图片 10 金币（每账号一次）
- **管理后台**：邀请码管理、用户管理、余额充值、GPU 算力 / API 消耗统计

## 环境要求

- Windows 电脑 + NVIDIA 显卡（建议 8G 以上显存）
- git（安装向导会自动检查，缺了会帮你装或提示下载地址）
- Python 3.11 以上（推荐 3.14）
- ComfyUI（安装向导可以帮你定位；没有的话也能自动帮你下载）

## 快速开始（3 步）

**第 1 步：首次安装**

双击项目根目录的 `安装向导.bat`，它会自动：

1. 检查 / 安装 git 和 Python；
2. 创建虚拟环境并安装依赖；
3. 让你确认 ComfyUI 的安装目录（也可以让它自动下载）；
4. 让你填写共享模型目录和工作流目录，并校验路径对不对；
5. 生成 `.env`（API Key 稍后自己填）和隐私数据文件。

装完后用记事本打开项目根目录的 `.env`，把 `OPENAI_API_KEY=` 后面填上你的 API Key（AI 提示词 Agent 功能要用）。

**第 2 步：日常启动**

双击 `一键启动.bat`，会一次启动三个服务：

| 服务 | 地址 | 用途 |
|---|---|---|
| 用户 WebUI | http://localhost:8642 | 用户注册、生成图片 |
| 管理后台 | http://localhost:8643 | 管理员：邀请码 / 用户 / 充值 / 统计 |
| ComfyUI | http://127.0.0.1:8188 | 本地绘图引擎（后台自动启动） |

在启动窗口里输入：

- `q` → 退出全部服务
- `l` → 查看 WebUI 最新日志（日志文件在 `data\logs\webui.log`）

**第 3 步：开始使用**

1. 打开管理后台 http://localhost:8643 ，首次运行设置管理员密码；
2. 「用户管理」里创建邀请码，发给用户；
3. 用户打开 http://localhost:8642 ，用邀请码注册，就能生成图片了。

## 常见问题

- **「免费充值额度」人机验证过不去？** 验证用的是 Cloudflare 服务，中国大陆网络下偶尔不稳定。换网络/换浏览器重试，或联系管理员手动充值。
- **想给用户送更多额度？** 改 `config.yaml` 里 `billing.signup_bonus` 和 `billing.free_recharge` 的数字，重启服务生效。
- **服务起不来？** 看 `一键启动.bat` 窗口，或检查 `data\logs\` 下的日志。
- **图片生成很慢/失败？** 检查 ComfyUI 窗口（标题 ComfyUI-1）有没有报错，显存是否够用。

## 隐私说明

你的 API Key（`.env`）、管理员密码和账号数据（`app\隐私数据\`）都只存在本机，**不会提交到 GitHub**。换电脑部署时，把 `.env.example` 复制成 `.env` 重新填 Key 即可。
