# app/webui/js —— 前端脚本

| 文件 | 服务 | 说明 |
|---|---|---|
| `app.js` | 用户页（8642） | 状态管理、选项加载、模型预设、生成任务轮询 + 进度条、AI 提示词 Agent 翻译与回填、图片灯箱 |
| `admin.js` | 管理后台（8643） | 登录、概览卡片、AI Agent 提示词列表/编辑/保存、修改密码、退出 |
| `features/` | 用户页 | 画质增强与 LoRA 面板的专属逻辑 |

注意：`app.js` 与 `admin.js` 的 API 前缀不同（`/mpwe/*` vs `/api/*`），
分别对应两个独立后端服务，不要混用。
