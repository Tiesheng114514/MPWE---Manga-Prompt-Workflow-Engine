# app/webui —— 前端页面与资源

原生 HTML/CSS/JS，无构建步骤，由两个后端服务分别托管：

- **用户服务（8642）**：`index.html`（AI 绘画主页）
- **管理后台（8643）**：`admin_login.html`（登录页）、`admin.html`（管理后台页）

## 目录结构

| 路径 | 说明 |
|---|---|
| `index.html` | 用户页：模型选择、AI 提示词 Agent、提示词输入、生成/画质增强/LoRA、历史 |
| `admin_login.html` | 管理员登录页 |
| `admin.html` | 管理后台：概览 / AI 提示词 Agent 编辑 / 改密 / 用户管理（占位） |
| `css/style.css` | 全部样式（含管理后台顶部导航、进度条、灯箱） |
| `js/app.js` | 用户页逻辑（选项加载、生成轮询、进度条、Agent 翻译、灯箱） |
| `js/admin.js` | 管理后台逻辑（登录、概览、Agent 编辑、改密、退出） |
| `js/features/` | 用户页子模块（画质增强、LoRA） |

## 约定

- 静态资源引用带版本号（`?v=YYYYMMDDx`），改动后记得递增，避免浏览器缓存旧版；
- 用户页接口走 `/mpwe/*`；管理后台接口走 `/api/*`（独立服务 8643）；
- 用户页**不含**管理后台入口（两个服务完全分离，入口只有 `启动管理员后台WebUI.bat`）。
