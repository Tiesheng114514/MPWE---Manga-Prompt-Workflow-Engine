# MPWE 功能文档

> Manga Prompt Workflow Engine —— 漫画 AI 绘画工作流引擎（内部工具）。
> 本文档覆盖全部已实现功能、配置方式、扩展指南与安全说明（非 README 的补充文档）。

## 1. 项目概述

MPWE 是一套本地运行的漫画创作工作流引擎：前端 WebUI（浏览器操作）+ 后端 Python
（FastAPI）+ 本地 ComfyUI Server API（绘图引擎）。当前已具备：文生图、画质增强、
LoRA 叠加、AI 提示词 Agent、管理员后台。

## 2. 快速开始

```bat
scripts\install_deps.bat      # 装依赖 + 初始化隐私数据（固定盐）
scripts\start_comfyui.bat     # 启动本地 ComfyUI（端口 8188）
scripts\start_webui.bat       # 启动 WebUI（http://localhost:8642）
scripts\启动管理员后台WebUI.bat # 首次运行设置管理密码，并打开管理员后台
```

依赖：Python 3.14 虚拟环境（`.venv`）、NVIDIA GPU + ComfyUI（含模型与 LoRA）。

## 3. 系统架构

```text
浏览器 WebUI（app/webui/，localhost:8642）
  ↓ HTTP /mpwe/*（/api/* 兼容旧路径）
FastAPI 后端（app/）
  ├─ comfyui/    ComfyUI Server API 客户端 + 工作流图构建器
  ├─ core/       任务管理（JobManager）+ Pydantic 数据模型
  ├─ prompting/  AI 提示词 Agent（两阶段流水线 + 配置驱动）
  └─ admin/      管理员后台（密码 + 会话 + Agent 提示词在线编辑）
  ↓
ComfyUI Server API（http://127.0.0.1:8188）
```

## 4. 功能模块

### 4.1 AI 绘画（文生图）

- 支持 Checkpoint 模型（SD/SDXL/Illustrious 系）与扩散模型（Z-Image/Anima 系）；
- 模型下拉按 `model_configs/*.yaml` 预设自动套用参数（步数/CFG/采样器/调度器/分辨率/CLIP 配置）；
- 生成任务异步提交 + 轮询，**实时进度条**从 ComfyUI websocket 拉取（`/ws` progress 事件）；
- 生成结果图片：居中展示、可点击放大（灯箱）、历史记录可回看；
- 历史记录为**文字懒加载**：列表只显示 ID/时间/模型/张数，点击才加载图片（低带宽友好）。

### 4.2 画质增强（超分重绘 + 脸部修复）

- Hires fix：IllustrationJaNai V3 超分放大 2 倍 → VAE 编码 → 低降噪二次采样；
- FaceDetailer：YOLOv8 检测脸部（`face_yolov8m.pt`）→ 单独重绘修复；
- 参数预设写在 `model_configs/*.yaml` 的 `quality:` 段，界面可开关；
- 与主生成共用同一套任务/进度条链路。

### 4.3 LoRA 叠加

- 后端按顺序串成 LoraLoader 链，权重可调；
- 每个模型的推荐 LoRA 与默认开关写在 `model_configs/*.yaml` 的 `loras:` 段；
- 类型约定：`quality` 恒加载、`style` 按需、`hands/hair` 修复类、`character` 角色、
  `nsfw/other` 按需求。

### 4.4 AI 提示词 Agent

- **输入**：用户大白话；**输出**：所选模型专属的全英文正向 + 负向提示词；
  （例外：Z-Image Turbo 官方明确无负面提示词，仅输出 POSITIVE，NEGATIVE 留空）
- **两阶段流水线**：
  1. 扩写 Agent（所有模型共用）：大白话 → 600-700 字中文「画面需求书」；
  2. 翻译 Agent（按模型特调）：需求书 → 英文 POSITIVE/NEGATIVE；
- **严格一对一**：翻译 Agent 只在 `agent_prompts.yaml` 的 `models:` 里配置过的模型上可用；
  已适配全部 10 个预设模型（Z-Image Turbo、Z-Anime、Anima、Animagine XL 4.0 双版本、
  ChenkinNoob、Illustrious XL v2.0、ItN's Comic Merge、NovelAI V2、One Obsession V14）；
  未配置的模型前端禁用按钮、后端拒绝请求（不混用）；
- **扩展方式**：新增模型专属 Agent 只需在 `agent_prompts.yaml` 的 `models:` 下复制一段，
  改 `model_file` 与全英文 `prompt` 即可；用户端按钮与管理后台编辑页自动适配，无需改代码
  （完整开发文档见 `app/prompting/README.md`）；
- 所有特调提示词均依据各模型官方文档/官方页面与社区指南重写（来源要点写在每个 `prompt:` 内）；
- 校验与兜底：纯英文、质量词前缀、关键道具补插、长度预算、重试（≤2 次）；
- **在线编辑**：管理员后台可直接编辑各 Agent 的系统提示词，保存即生效（无需重启）。

### 4.5 管理员后台（独立端口 8643）

- 密码登录：**首次运行「启动管理员后台WebUI」手动设置**（8-128 位）；
- **与用户 WebUI 完全分离**：管理后台独立监听 `http://127.0.0.1:8643`，
  公网 WebUI（8642 / Cloudflare 隧道）不包含任何管理入口；
- 密码哈希：**PBKDF2-HMAC-SHA256，20 万次迭代，固定盐**（安装时随机生成）；
- 会话：内存实现，8 小时，Cookie `mpwe_admin`（HttpOnly、SameSite=Lax）；
- 登录限流：每 IP 60 秒最多 5 次尝试；
- 功能页：概览（后端/ComfyUI/LLM Key/适配模型 + 总消耗/总算力）、AI 提示词 Agent 在线编辑、
  用户管理（用户列表/邀请码管理/充值调整/停用启用/重置密码）、
  GPU 算力消耗、API 消耗、修改管理密码；
- 命令行改密：`scripts\修改管理员密码.bat`。

### 4.6 模型预设体系

每个模型一个 YAML（`model_configs/*.yaml`），字段包括：显示名、模型文件名、类别、
工作流、生成参数（steps/cfg/sampler/scheduler/分辨率/CLIP）、提示词写法说明、
负面词默认值、画质增强预设、LoRA 推荐列表。

## 6. 扩展指南

### 6.1 新增一个模型

1. 模型文件放入 ComfyUI 共享模型目录；
2. `model_configs/` 新建 `模型名.yaml`（参照 `model_configs/README.md` 规范）；
3. 重启 WebUI 自动识别，无需改代码。

### 6.2 新增 / 特调一个 AI Agent

编辑 `app/prompting/agent_prompts.yaml`：

- 共用扩写 Agent：`expand_agent.prompt`（所有模型一致）；
- 某模型专属翻译 Agent：`models.<model_file>.translate_agent.prompt`；
- 新增模型 = 在 `models:` 下复制一段，改 `model_file` 与全英文 `prompt`；
- 保存即生效（运行时按 mtime 自动重载）；也可在管理员后台「AI 提示词 Agent」页在线编辑；
- 未配置专属 Agent 的模型：后端拒绝翻译请求（严格一对一，不混用）。

### 6.3 新增一个生成工作流

在 `app/comfyui/workflows/` 新建模块并注册：

```python
@register("my_workflow")
def build_my_workflow(**params) -> dict:
    """返回 ComfyUI API 格式的工作流图。"""
    return {...}
```

### 6.4 新增一个后端接口

在 `app/api/routes.py` 的 `create_router()` 中新增路由；前端统一走 `/mpwe` 前缀。

## 7. 安全与隐私

- 管理员密码不明文存储：`app/隐私数据/secrets.json` 仅存固定盐 + PBKDF2 哈希，
  校验用常量时间比较（`hmac.compare_digest`）；
- 用户密码同样 PBKDF2-HMAC-SHA256 + **每用户独立随机盐**，存 `app/隐私数据/accounts.db`；
  用户名明文（管理员后台需要查看）；API 接口不返回盐/哈希；
- 隐私目录整体 git 忽略，**严禁提交**；API 不返回盐/哈希；日志不打印密码；
- 登录 Cookie：HttpOnly + SameSite=Lax，8 小时过期；登录限流防爆破；
- 用户会话：HttpOnly Cookie `mpwe_user`（30 天自动登录），密码不进 Cookie；
- 双钱包计费：API 钱包（DeepSeek 按 token 峰谷价实时扣费）与图片钱包（0.3 元/张）
  分开记账，管理员后台可充值/调整并留流水；显示上 **API 用银币（🥈）、图片用金币（🪙）**（1 币=1 元）；
  新用户注册自动赠送 API 0.5 银币 + 图片 3 金币，右上角「免费充值额度」
  过 Cloudflare 人机验证后一次性再送 0.5 银币 + 10 金币（`config.yaml` 可调）；
- `.env`（LLM API Key）git 忽略；配置接口不返回 Key；
- 本地工具默认只监听 127.0.0.1；公网部署需自行加反向代理与 HTTPS（Cookie 需 Secure）。

## 8. API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/mpwe/health` | 后端 + ComfyUI 健康状态 |
| POST | `/mpwe/generate` | 提交生成任务 |
| GET | `/mpwe/jobs` / `/mpwe/jobs/{id}` | 任务列表 / 状态（含进度百分比） |
| GET | `/mpwe/jobs/{id}/images/{i}` | 任务输出图片 |
| POST | `/mpwe/prompt/translate` | 提交提示词翻译任务 |
| GET | `/mpwe/prompt/jobs/{id}` | 翻译任务状态 |
| GET | `/mpwe/prompt/agents` | 已适配 Agent 的模型清单 |
| GET | `/mpwe/auth/me` | 当前用户 + 双钱包余额（未登录 401） |
| POST | `/mpwe/auth/register` | 注册（邀请码，无需人机验证），自动登录 |
| POST | `/mpwe/auth/free-claim` | 领取免费充值额度（需 Turnstile 人机验证，每账号一次） |
| POST | `/mpwe/auth/login` / `logout` | 登录 / 登出 |
| GET | `http://127.0.0.1:8643/` / `/login` | 管理后台页面 / 登录页 |
| POST | `/api/login` / `logout` | 登录 / 登出 |
| GET | `/api/session` / `overview` | 会话状态 / 概览（需登录） |
| POST | `/api/password` | 修改管理密码（需登录） |
| GET/PUT | `/api/prompts[/{id}]` | Agent 提示词列表 / 在线编辑（需登录） |
| GET/POST | `/api/invite-codes[/{code}]` | 邀请码列表 / 创建 / 删除（已使用拒绝） |
| GET | `/api/users[/{uid}]` | 用户列表（不含盐/哈希）/ 详情 + 流水 |
| POST | `/api/users/{uid}/balance` | 充值/调整余额（API 或图片钱包） |
| POST | `/api/users/{uid}/toggle-active` / `reset-password` | 停用启用 / 重置密码 |
| GET | `/api/stats/gpu` / `/api/stats/api` | GPU 算力 / API 消耗统计（按用户） |
