# MPWE 多用户与任务系统（Phase 2 已实现）

> 本文档描述多用户体系的最终设计与实现：注册/登录、邀请码、Cloudflare Turnstile、
> 双钱包计费、GPU 算力统计、任务持久化与数据隔离。

## 1. 目标（均已实现）

1. **邀请码注册**：无邮箱/手机；管理员后台手动创建邀请码（可批量、可配每人上限），
   已有人注册的邀请码不可删除；**注册不设人机验证**（防机器人靠邀请码门槛 + 免费额度领取验证）。
2. **自动登录**：注册/登录后下发 HttpOnly 会话 Cookie（`mpwe_user`，30 天），
   用户名密码不进 Cookie；未登录时页面弹出注册/登录弹窗（不另开页面）。
3. **用户 ID**：从 `00001` 起递增，超过 99999 继续往后（如 `100000`），不重置。
4. **数据隔离**：每个用户只能看到、操作自己的任务/图片/账单；管理员可查看全部。
5. **任务持久化**：任务、图片元数据、生成参数写入 SQLite；图片落盘
   `data/users/<uid>/<job_id>/`，重启不丢。
6. **双钱包计费**：API 钱包（DeepSeek 真金白银，按 token 峰谷价实时扣费）与
   图片钱包（本地 GPU，0.3 元/张）**完全分开**；后台可充值/调整并留流水。
7. **GPU 算力统计**：记录每任务 GPU 耗时（秒）+ 估算算力（TFLOPS·时），
   概览显示总消耗，新增「GPU 算力消耗」「API 消耗」两个板块按用户统计。
8. **历史记录低带宽**：历史列表默认只显示文字元数据，点击才加载图片；
   图片优先读本地缓存并带 Cache-Control/ETag。

## 2. 数据存储

两个 SQLite 库（都已被 `.gitignore` 排除）：

```text
app/隐私数据/accounts.db   # users / invite_codes / sessions（凭据域）
data/mpwe.db               # wallets / billing_entries / jobs / job_images（业务域）
data/users/<uid>/<job_id>/ # 每账号输出图片
```

### accounts.db

| 表 | 说明 |
|---|---|
| `users` | uid（00001 起）、用户名（明文）、盐、PBKDF2 哈希、来源邀请码、状态 |
| `invite_codes` | code、max_invites、used_count；used_count>0 禁止删除 |
| `sessions` | HttpOnly 会话 token（30 天） |

### mpwe.db

| 表 | 说明 |
|---|---|
| `wallets` | 每用户 `api_balance_mli`、`image_balance_mli`（金额单位：厘=0.001 元） |
| `billing_entries` | 总台账：api/image 消费 + api_recharge/image_recharge 充值，均带余额快照 |
| `jobs` | 任务：user_id、workflow、params(JSON)、状态、时间戳、gpu_seconds、gpu_flops_estimate |
| `job_images` | 输出图：序号、ComfyUI 文件名、本地路径、宽高 |

## 3. 计费

### API 计费（实时）

- 每次 LLM 调用（扩写 + 翻译 + 重试）从 `llm.py` 的 `usage` 取 token，
  按 DeepSeek V4 Flash 官方峰谷价（`config.yaml` 的 `billing.api`）计费并**立刻扣 API 钱包**；
- 高峰时段（本地 9:00-12:00、14:00-18:00）为闲时的 2 倍：
  输入缓存命中 / 未命中 / 输出 = 0.05 / 1.5 / 4.5（元/百万 token，闲时），高峰翻倍；
- 钱包余额不足时拒绝发起翻译/生成。

### 图片计费（本地 GPU）

- 任务成功出图后按张数 × 0.3 元（`config.yaml` 可调）扣图片钱包；
- 提交任务前先预检余额（≥ batch_size × 单价），不足返回 402。

### 充值

管理员后台「用户管理 → 详情」对 API / 图片钱包分别充值或调整（可为负），
不允许余额变负，所有操作写入 `billing_entries` 流水。

新用户注册时自动赠送额度（`config.yaml` → `billing.signup_bonus`，可配置）：
默认 **API 0.5 银币 + 图片 3 金币**，以「新用户注册赠送」流水入账。

右上角「免费充值额度」：点击后需通过 Cloudflare Turnstile 人机验证，
通过后一次性再送 **API 0.5 银币 + 图片 10 金币**（`billing.free_recharge` 可配，每账号限一次）。
显示上区分两种币：**API 用银币（🥈）、图片用金币（🪙）**；1 币 = 1 元，数据库仍以厘存储。

## 4. GPU 算力统计

- **GPU 耗时（秒）**：任务 started_at → finished_at，真实记录；
- **估算算力**：按 步数 × 分辨率 × 模型系数 ×（超分/脸部修复倍率）估算 FLOPs，
  展示为 TFLOPS·时（`app/core/gpu_metrics.py`，粗估用于横向比较，非精确计量）；
- 后台「概览」= 全部用户合计；「GPU 算力消耗」= 按用户排行。

## 5. 接口

### 用户端（`/mpwe/*`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/mpwe/auth/me` | 当前登录用户 + 双钱包余额（未登录 401） |
| POST | `/mpwe/auth/register` | `{username, password, invite_code}`（无需人机验证） |
| POST | `/mpwe/auth/free-claim` | `{turnstile_token}` 领取免费充值额度（每账号一次） |
| POST | `/mpwe/auth/login` | `{username, password}`，下发 HttpOnly Cookie |
| POST | `/mpwe/auth/logout` | 注销会话 |
| POST | `/mpwe/generate` | 需登录 + 图片钱包预检；任务落库，出图后按张扣费 |
| GET | `/mpwe/jobs` | 仅当前用户任务（默认文字元数据） |
| GET | `/mpwe/jobs/{id}/images/{i}` | 本地缓存优先，缺失回退 ComfyUI 代理，带缓存头 |
| POST | `/mpwe/prompt/translate` | 需登录 + API 钱包预检；每次 LLM 调用实时扣费 |

### 管理员端（`/api/*`，独立端口 8643）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/invite-codes` | 邀请码列表 / 批量创建（每行一个 + 统一人数上限） |
| DELETE | `/api/invite-codes/{code}` | 删除（已有注册者拒绝） |
| GET | `/api/users` | 用户列表（不含盐/哈希）+ 钱包 + 消耗 + 算力 |
| GET | `/api/users/{uid}` | 用户详情 + 账单流水 |
| POST | `/api/users/{uid}/balance` | 充值/调整余额 `{wallet, amount, note}` |
| POST | `/api/users/{uid}/toggle-active` | 停用/启用 |
| POST | `/api/users/{uid}/reset-password` | 重置密码 |
| GET | `/api/stats/gpu` | GPU 算力统计（按用户） |
| GET | `/api/stats/api` | API 消耗统计（按用户） |
| GET | `/api/overview` | 概览（含总消耗/总算力/用户数/邀请码数） |

## 6. Cloudflare Turnstile

- Site Key 下发到 `/mpwe/config`（公开），Secret Key 只在服务端（`.env`），
  领取「免费充值额度」时服务端调 `siteverify` 校验 token（5 分钟有效、一次性）；
- 注册不再要求人机验证（中国大陆网络下 Turnstile 不稳定，见 troubleshooting）；
- 本地/测试可用 `TURNSTILE_ENABLED=0` 关闭验证；
- 注意：Turnstile widget 绑定的域名与访问域名不一致时验证会失败，
  本地 localhost 调试需在 Cloudflare 控制台把 `localhost` 加入 widget 域名，或临时关闭。
